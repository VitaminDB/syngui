# syngui — что осталось

> Статусы: `[ ]` — не начато, `[~]` — частично (в пункте — только то, что осталось).
> Порядок: внутри раздела — сверху то, что логично делать раньше.

## Lottie (`syngui/src/lottie`, виджет `Lottie`)

- [ ] **аниматоры текста** (`t.a`): range-селекторы (start/end/offset, единицы
      проценты/индексы, формы square/ramp/triangle) и анимируемые свойства по
      буквам — позиция, поворот, масштаб, непрозрачность, цвет заливки/обводки,
      трекинг. Сейчас аниматоры пропускаются (лог в `parse_text`), текст статичен.
      Самый частый недостающий кусок: эффекты «печатающейся строки», волны букв.
- [ ] **текст по контуру** (`t.p`: path, f/l-отступы, выравнивание): буквы
      раскладываются вдоль маски слоя. Частично есть основа — `Polyline::slice`
      и длины дуг в geom.rs.
- [ ] **merge paths для обводок**: булевы операции сейчас действуют только на
      заливки (маски покрытия в `style_fill_mask`); обводка рисует исходные
      контуры. Для честной обводки результата нужна векторная булева операция
      над контурами (пересечения кривых, обход графа) — отдельная задача.
- [ ] **zig zag со сглаживанием** (`pt: 2`): сейчас волнистый режим рисуется
      уголками, как `pt: 1`. Нужны дуги/безье между пиками (`zigzag_path`).
- [ ] **выражения** (`x` на свойствах, `$bm_rt`): нужен мини-интерпретатор JS
      (bodymovin-подмножество: арифметика, Math, var, функции loopOut/wiggle…).
      Сейчас свойства с выражениями играют по ключевым кадрам, выражение
      игнорируется. Начать с каталога реальных выражений из образцов.
- [ ] **3D-слои и камера**: `ddd: 1`, повороты `rx`/`ry`, ориентация `or`,
      слой-камера (ty 13) с перспективой. Сейчас берётся только 2D-проекция
      (`rz`), камера пропускается как Unsupported.
- [ ] **layer styles** (`sy`: Drop Shadow, Inner Shadow, Outer/Inner Glow,
      Stroke, Bevel): похожи на эффекты, большинство ложится на готовые
      `Pixmap::blur`/`shadow_of`.
- [ ] **остальные эффекты слоёв**: Tritone (23), Hue/Saturation, Levels,
      Radial Blur, Stroke (22), CC-эффекты по мере встречаемости. Каркас разбора
      и применения готов (`parse_effects` / `apply_effects`).
- [ ] **mask expand** (`x` у маски): расширение/сужение покрытия маски; можно
      реализовать через `offset_polyline` по контуру маски.
- [ ] **dotLottie: выбор анимации** — `Lottie::from_file` играет первую из
      manifest.json; нужен API выбора по id (`multiple_animations.lottie`
      из lottie-ios — готовый образец) и чтение темы/скорости из манифеста.
- [ ] **проверить семантику `sr` (time stretch) для свойств самого слоя**:
      сейчас ключевые кадры свойств считаются во времени композиции, `st`/`sr`
      сдвигают только время дочерней прекомпозиции (так сошлись все образцы,
      включая Lottie Logo). В lottie-web растяжение, похоже, применяется и к
      свойствам слоя — найти/сделать образец с `sr != 1` на shape-слое и сверить.
- [ ] **производительность**: грязные регионы между кадрами (сейчас кадр
      растеризуется целиком), SIMD-заливка строк покрытия (`wide` уже в
      зависимостях), параллельные слои через отдельный пул.

## Виджет `Lottie`

- [ ] **события по маркерам**: колбэк `on_marker(name)` при проходе кадра
      маркера (маркеры уже разобраны в `Composition::markers`).
- [ ] **кэш кадров для маленьких анимаций**: иконки-анимации (как `done.json`)
      дешевле отрендерить один раз в атлас кадров, чем крутить растеризатор
      каждый тик (порог по площади × длительности).
