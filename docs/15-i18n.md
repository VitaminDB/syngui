# 15. Локализация (i18n)

Модуль `syngui::i18n` (фича `i18n`, включена по умолчанию) даёт приложению
каталоги строк, текущий язык как сигнал и живое переключение без перезапуска.
Зависимостей нет: формат каталога свой, правила множественного числа — таблица
в `plural.rs`, определение языка системы — `system.rs`.

```rust
use syngui::prelude::*;

syngui::i18n::register_catalogs(&[
    include_str!("../i18n/en.lang"),
    include_str!("../i18n/ru.lang"),
]);
syngui::i18n::set_language(syngui::i18n::system_language());

App::new().run(|_| {
    Box::new(DecoratedBox::new().child(|| {
        syngui::i18n::subscribe();          // корень перестраивается при смене языка
        build_root()
    }))
});

fn build_root() -> impl Widget {
    Column::new()
        .child(Text::new(tr!("app.title")))
        .child(Text::new(tr!("greeting", name = "Anna")))
        .child(Text::new(trn!("files.count", 5)))
}
```

## Формат каталога `.lang`

Один файл на язык, кодировка UTF-8, одна пара на строку.

```
# комментарий
@tag = "ru"                        # обязателен, BCP47-подобный тег
@name = "Русский"                  # обязателен, название на самом языке
@english = "Russian"               # необязателен
@plural = "east-slavic"            # необязателен, иначе по базовому языку

app.title = "Мой редактор"
greeting = "Привет, {name}!"
chat.error = "Не удалось открыть \"{path}\":\n{error}"
files.count.one  = "{n} файл"
files.count.few  = "{n} файла"
files.count.many = "{n} файлов"
```

- Ключ: `[A-Za-z0-9_.-]`, значение только в двойных кавычках; эскейпы `\n \t \" \\`.
- `#` после закрывающей кавычки — комментарий.
- Плейсхолдеры `{name}` подставляются по имени; неизвестные остаются как есть,
  одиночная `{` — литерал.
- Формы числа — суффиксы `.zero .one .two .few .many .other`; при поиске
  берётся форма по правилу языка, затем `.other`, затем ключ без суффикса.
- Дубликат ключа: последний побеждает (`warn` в лог). Битая строка — ошибка с
  номером строки, `register_catalogs` пропускает такой файл целиком.

`Catalog::parse` доступен публично — на нём удобно строить тест паритета
ключей между языками в приложении.

## API

| Вызов | Что делает |
|---|---|
| `register_catalog(&'static str)` / `register_catalogs(&[…])` | Регистрирует каталоги приложения; один тег дважды — слияние, поздний побеждает |
| `set_language(impl Into<Lang>)` | Меняет язык; принимает `"ru"`, `"pt_BR.UTF-8"`, `Lang` |
| `language()` | Эффективный язык после разрешения; внутри билдера подписывает элемент |
| `requested_language()` | Что запросили через `set_language`, до разрешения |
| `languages()` | Список `LangInfo { tag, name, english }` для переключателя (каталоги приложения) |
| `system_language()` | Язык ОС: `LC_ALL/LC_MESSAGES/LANG/LANGUAGE`, затем платформенный источник |
| `tr("k")`, `tr!("k")`, `tr!("k", name = v)` | Перевод с подстановкой |
| `trn("k", n)`, `trn!("k", n, extra = v)` | Форма числа, `{n}` подставляется сам |
| `try_tr("k")` | `Option<String>` без фолбэка на ключ — для динамических ключей |
| `subscribe()` | Подписать текущий `Reactive` на смену языка без обращения к строкам |

Цепочка поиска: запрошенный тег → тот же базовый язык (`pt-PT` → `pt-BR`) →
`en` → сам ключ. Ключ, которого нет нигде, один раз пишется в лог уровня
`debug` и возвращается как есть. Внутри одного языка каталог приложения
просматривается раньше встроенного, поэтому строки виджетов syngui можно
переопределять из приложения по тем же ключам.

`Lang::parse` нормализует `ru_RU.UTF-8` → `ru-RU`, `zh-Hans-CN` → `zh-CN`,
`pt_br` → `pt-BR`; `C`/`POSIX` → `None`.

## Что перестраивается

`tr!` не делает `Text` реактивным сам по себе: виджеты берут `impl Into<String>`
и запоминают строку при сборке. Живым переключение становится потому, что
`tr!`/`language()`/`subscribe()` читают сигнал ревизии — и элемент `Reactive`
(или `.child(|| …)`), внутри которого выполнился билдер, помечается на
перестройку при `set_language`. Правила:

1. Строки должны резолвиться внутри билдера `Reactive`. Литерал, собранный
   снаружи (статичный `Column::new().child(Text::new(tr!(..)))` без замыкания),
   переведётся один раз при старте.
2. Самый простой способ покрыть всё приложение — обернуть корень в
   `DecoratedBox::new().child(move || { i18n::subscribe(); build_root() })`.
   Реконсиляция идёт на месте: совпавшие по типу элементы обновляются через
   `update()`, поэтому скролл, текст в полях и раскрытые выпадашки переживают
   смену языка.
3. `RouterView` и `MarkdownView` перестраивают своих детей при обновлении
   родителя — активная страница и контекстное меню получают новые подписи.
4. `tr()` можно звать из рабочих потоков (уведомления, статусы) — состояние
   переводчика лежит в `Mutex`; подписка на сигнал происходит только с главного
   потока. `set_language` из воркера маршалится на главный поток.
5. `create_effect` — не место для `tr!`: подпишется эффект, а не элемент.

## Встроенные строки виджетов

Подписи диалогов (`dialog.ok`, `dialog.cancel`), `TimePicker`
(`time_picker.am/pm/ok`), `ColorPicker` (`color_picker.hex`), `Image`
(`image.loading`), тулбар `MarkdownEditor` (`markdown_editor.edit/preview/split`),
панель поиска редактора кода (`code_editor.find`, `code_editor.find_query`,
`code_editor.goto_line`, `code_editor.goto_line_input`), меню `MarkdownView`
(`markdown_view.copy/select_all/copy_all`), `VideoView`
(`video.play/pause/mute/unmute`, `video.a11y`, `frames_view.a11y`),
`Multiselect` (`multiselect.placeholder/search/empty`), `Dropdown`
(`dropdown.placeholder`). Встроенные каталоги — `syngui/i18n/*.lang` на 14
языков: en, ru, de, fr, es, it, pt-BR, pl, uk, kk, tr, zh-CN, ja, ko.
`set_dialog_labels(..)` остаётся явным переопределением поверх каталога.

`set_language` также переключает локаль календаря по умолчанию
(`CalendarLocale::from_id`, иначе английская).

## Правила множественного числа

| Правило | Языки | Категории |
|---|---|---|
| `one-other` | en, de, es, it, tr, kk | one, other |
| `zero-one-other` | fr, pt | one (0 и 1), other |
| `east-slavic` | ru, uk | one, few, many |
| `polish` | pl | one, few, many |
| `other-only` | zh, ja, ko | other |

Неизвестный язык получает `one-other`; в каталоге можно переопределить
`@plural`. Считаются только целые числа.

## Шрифты для CJK

Основной шрифт и его жирный вариант покрывают латиницу и кириллицу. Для
китайского, японского и корейского атлас держит цепочку запасных лиц: при первом
непокрытом символе определяется письменность (`text::script`), и через
`font_discovery` подбирается системное семейство по таблице для ОС (Noto Sans
CJK, Source Han Sans, PingFang, Microsoft YaHei, Malgun Gothic…). Файл шрифта
читается один раз и разделяется через `Arc`; жирный CJK использует то же лицо.
При переполнении атласа он сбрасывается между кадрами, кэш формы строк
инвалидируется по поколению атласа.

Для web, где системных шрифтов нет, запасное лицо задаётся явно:

```rust
App::new()
    .with_font_url("fonts/DejaVuSans.ttf")
    .with_fallback_font_url("fonts/NotoSansCJKsc-Regular.otf")
```

Переносы строк: у CJK нет пробелов, поэтому `text::line_break` разрешает
перенос между идеографами, склеивая закрывающую пунктуацию с предыдущим
символом, а открывающие скобки — со следующим.

## Ограничения

- Шейпинга нет: арабское письмо, деванагари и RTL не поддерживаются.
- Числа форматируются через `format!` — разделитель дробной части всегда `.`,
  группировки разрядов нет.
- Названия месяцев в `CalendarLocale` есть для ru/en/de/fr/es; остальные языки
  получают английский календарь.
