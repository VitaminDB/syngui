# Печать (`syngui::print`, фича `print`)

Окно печати с предпросмотром и настройками, принтеры CUPS, печать в PDF.

```rust
use syngui::print::{ImageDocument, PageRange, PrintDialog, PrintImage, outcome_text};

let open = use_signal(false);
let doc = ImageDocument::new("photo.jpg", 1, 0, move |_| PrintImage::load(&path))
    .default_range(PageRange::Current);
PrintDialog::new(open, Arc::new(doc))
    .on_done(|r| if let Ok(o) = r { flash(outcome_text(&o)) })
    .build() // Portal — положить в Stack поверх окна
```

## Что умеет окно

- **Принтер**: очереди CUPS (`lpstat`), состояние и адрес, принтер по умолчанию; «Сохранить в PDF» всегда в списке.
- **Копии**, «Разобрать по копиям»; **страницы** — все, текущая, выбранные («1-3, 5, 8-»).
- **Бумага**: размеры из PPD принтера (точные размеры и непечатаемые поля — `*PaperDimension`, `*ImageableArea`).
- **Ориентация**: авто (широкая картинка — альбомный лист), книжная, альбомная.
- **Цвет**: цветная/ч-б (`ColorModel` драйвера + `print-color-mode`); у монохромного принтера предпросмотр сразу серый.
- **Двусторонняя печать** (`Duplex` из PPD).
- **Размещение картинок**: 1, 2, 4, 6, 9 на листе; вписать или заполнить с обрезкой; поля.
- **Страницы документа** ([`PageDocument`]: PDF, книги, листы со своим размером): 1, 2, 4, 6, 9 страниц
  на листе; **масштаб** — по размеру листа, уменьшать крупные, фактический размер (100 %, страница
  ложится по центру листа — A4 на A4 точно), свой % (10–400; при нескольких на листе — от ячейки);
  «Авто»-ориентация по странице (две книжные на листе — альбомный лист).
- **Настройки принтера**: все остальные настройки драйвера (тип бумаги, лоток, качество, экономия тонера…) — выпадающими списками; значения, сохранённые пользователем (`lpoptions -p`), подставляются.
- Предпросмотр рисуется тем же кодом, что и PDF для принтера: что видно — то и напечатается.
- Последние выбранные настройки помнятся: `$XDG_CONFIG_HOME/syngui/print.conf`.

## Как печатается

Листы собираются в PDF (фото — JPEG, графика — без потерь, картинки не больше 300 точек на дюйм)
и отдаются `lp -d ОЧЕРЕДЬ -o PageSize=… -o media=… -o Duplex=… …`. PPD берётся у сервера CUPS
по HTTP (`/printers/ИМЯ.ppd`, затем сокет `/run/cups/cups.sock`). Без CUPS (телефон) остаётся PDF.

## Свои документы

Страницы со своим размером — готовым `PageDocument`:

```rust
let doc = PageDocument::new(title, sizes_mm, current, move |i, w_px, h_px| {
    // растр страницы i размером примерно w_px×h_px (предпросмотр — мелкий, печать — 300 dpi)
    render_page(i, w_px, h_px)
})
.default_range(PageRange::Current);
```

`PrintDocument` — пункты (страницы, картинки) и `render(items, sheet, settings, preview)` →
картинки на листе (`PlacedImage`: прямоугольник и рамка обрезки в мм). Текстовый документ
отдаёт страницу растром на всю `sheet.printable`; `preview` — длинная сторона растра предпросмотра.

## Принтеры из программ

`cups::printers()`, `printer_ppd()`, `jobs()`, `cancel_job()`, `set_default()`,
`user_defaults()`/`set_user_defaults()` (настройки по умолчанию пользователя), `set_enabled()`,
`print_test_page()` — для менеджера принтеров в настройках.

Стили — `styles/print.mss` (классы `print-*`), строки — ключи `print.*` в `i18n/*.lang`.
